# Mon Chat 2 — Plan d'implémentation

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:executing-plans to implement this plan task-by-task.

**Goal:** Construire `chat2/`, version réaliste du tamagotchi *Mon Chat*, avec un chat procédural à fourrure, un environnement PBR (Poly Haven), un cycle jour/nuit, le même gameplay que la v1, des tests `node --test`, ESLint via Docker, et déployer sur le Pi.

**Architecture:** Pages statiques ES modules + Three.js 0.170 vendorisé (cœur + addons `examples/jsm`). Le chat est généré au chargement (SDF → marching cubes → skinning automatique → shells de fourrure) et animé par code (machine d'états + poses + IK). L'environnement mélange géométrie procédurale texturée (maison, sol, clôture) et modèles glTF photoscannés (meubles, plantes). La logique pure (jauges, sauvegarde, boutique, SDF, MC, skinning, comportement) vit dans des modules sans DOM ni WebGL, testables sous Node.

**Tech Stack:** Three.js 0.170.0 (`three` + `three/addons/`), WebGL2, ES modules, `node --test` (Node 20), ESLint 9 via Docker `node:20`, Chrome headless pour captures, Poly Haven API (CC0).

**Design :** `docs/plans/2026-09-02-chat2-design.md`.

## Phase B — Le chat procédural

### Task 4 : SDF du chat (`cat/sdf.js`) — TDD

**Files:** Create `chat2/js/cat/sdf.js`, `chat2/test/sdf.test.js`.

API pure (tableaux `[x,y,z]`, pas de THREE) :
```js
export function sdCapsule(p, a, b, r)            // distance à une capsule
export function sdEllipsoid(p, c, radii)          // approximation standard (k0/k1)
export function sdRoundCone(p, a, b, r1, r2)      // cône arrondi (pattes, queue, museau)
export function smin(a, b, k)                     // smooth-min polynomial : h=max(k-|a-b|,0)/k; min(a,b)-h*h*k*0.25
export function buildCatParts(opts)               // → [{ bone:'head', shapes:[{type,params…}], blend:k }]
export function catDistance(parts, p)             // smin de toutes les formes ; retourne { d, partIndex } (partIndex = forme la plus proche)
```
Anatomie (unités : mètres, chat ~0.45 m long hors queue, hauteur épaule 0.25) : tronc capsule (bassin→poitrail, r 0.09→0.10), poitrail ellipsoïde,
cou capsule, tête ellipsoïde 0.075, museau ellipsoïde bas-avant, joues ×2, front, oreilles cônes arrondis, 4 pattes (haut/bas/pied : roundCone r 0.035→0.025, pied ellipsoïde), queue 6 roundCones r 0.022→0.012 (pose de repos : courbe vers le haut).
Chaque forme porte `bone` (nom d'os) pour T6.

Tests : `smin(a,b,k) ≤ min(a,b)` ; centre d'une capsule → d<0, loin → d>0 ; `catDistance` au centre du tronc <0, à (0,1,0) >0 ; `partIndex` d'un point dans la tête = index d'une forme dont `bone==='head'`.
